# Księga Vojtiecha Havela

Pierwszy prototyp interaktywnej księgi 3D z okładką opisaną „Vojtiech Havel — 1400 rok pański”. Wnętrze zawiera puste, postarzone strony przeznaczone do późniejszego uzupełnienia kroniką.

## Uruchomienie

Strona jest samodzielnym plikiem HTML i korzysta z Three.js ładowanego z jsDelivr. Po wdrożeniu GitHub Pages będzie dostępna pod adresem:

https://hogcraft2-cpu.github.io/sacrascript-medieval/vojtiech-havel/

## Sterowanie

- Kliknij księgę lub „Otwórz księgę”, aby otworzyć okładkę.
- „Następna strona” i „Poprzednia” zmieniają strony.
- Strzałki klawiatury również przewracają strony.

To prototyp wizualny; kolejnym etapem będzie dopracowanie animacji przewracania pojedynczych kartek i system dodawania treści, ilustracji, herbów oraz map.
